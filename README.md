# 🎃 Halloween Cat & Ghost Animation 👻

A spooky, atmospheric Halloween scene featuring an animated cat and a floating ghost. Built entirely with **HTML and CSS**, this project focuses on expressive character motion and ambient visual effects—no JavaScript involved.

## ⚙️ Features

- 🎨 **Pure HTML & CSS** — no JavaScript, no frameworks
- 🐱 **Animated Cat**
  - Ear movement
  - Tail swishing
  - Subtle body motion
- 👻 **Floating Ghost**
  - Smooth vertical movement
  - Wavy bottom animation
- 🌙 **Atmospheric Night Scene**
  - Glowing moon with crater details
  - Twinkling stars
  - Window reflections
- 📱 **Responsive Design**
  - Adapts to different screen sizes
- 💜 **Stylized Color Palette**
  - Purple tones
  - Dynamic shadows and highlights

---

## 🎞️ CSS Animations Included

- 👻 Ghost floating motion
- 🌊 Ghost bottom wave effect
- 🐱 Cat tail swishing
- 🐾 Cat ear movements
- ✨ Star twinkling animations

## 🚀 Getting Started

1. Clone or download the repository
2. Open `index.html` in your browser  
   **or**
3. Use VS Code **Live Server** for local preview

No build tools or dependencies required.
